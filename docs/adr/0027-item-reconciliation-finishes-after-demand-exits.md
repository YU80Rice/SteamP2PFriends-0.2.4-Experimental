# 0027: Item 已启动结算在需求消失后继续收尾

用户在2026-10-08选择Q13的A：当前会话/区域仍有效时，即使最后有效需求离开，已经启动的这一轮结算仍继续分帧收尾，不暂停、不撤销、不重做已执行的删除和补货。没有等待者便不发清单；完成后立即休眠，不继续启动自然周期。

已经删掉或补上的物资就是当前权威结果。下次有效需求到来，从这次收尾后的状态重新判断是否需要结算，不从半截进度接着跑。若收尾期间重新出现有效需求，仍遵循ADR0026等待同一次结果，不因曾经无人便并列重算。

本条只允许有效会话/区域中已有结算的有限收尾，不授权换图或会话结束后继续操作旧仓库；会话/区域身份失效按既有隔离规则处理。用户原文见 [原生职责复用与按需运行的边界是什么](../../.scratch/map-c-stage-world-state-migration/ticket-runtime-duty-boundary/ticket.md) 的Q13，细化ADR0026当时未决的无人收尾边界。
