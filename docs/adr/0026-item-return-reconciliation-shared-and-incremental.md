# 0026: Item 返区结算按区域共享并分帧完成

用户在2026-10-08选择Q12的A：优先流畅，返区物资较多时分几帧完成listen-host权威结算；玩家继续走动，物品稍后出现，完成结算后才能拾取。每次返区结算由首个有效需求启动，同一区域正在进行的这一次结算不按观察者并列执行，后来者等待同一次结果。

先清过期自然物资，再按原生资格尝试补当前缺量；区域清单必须等该次结算完成后发送，Host本地呈现/交互同样不能消费半结算的旧状态。后来者不另抽物资、不重置年龄，也不通过先发旧清单绕过完成顺序。

正常分帧与等待同一次结果属于正常进度，不消耗异常恢复预算、不因超过失败重试期限而报失败；失败提示和手动重试只用于实际异常。这里等待的是主机权威结算完成，不新增客户端全区ACK或模型齐全门。

“只做一次”针对本次区域返区结算，不表示以后再次休眠/返区永远不再结算。最后有效需求在结算期间消失时如何处理，留待下一轮裁定。本条细化ADR0020/0022，完整用户原文见 [原生职责复用与按需运行的边界是什么](../../.scratch/map-c-stage-world-state-migration/ticket-runtime-duty-boundary/ticket.md) 的Q12。
