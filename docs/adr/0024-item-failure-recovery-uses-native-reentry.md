# 0024: Item 异常恢复沿用原生提示与离区返区

用户在恢复载体选择中接受：

> 推荐：沿用原生；提示后手动重试，必要时离开该区域的物品加载范围再回来。正常进区不受影响。

Item 局部有限恢复耗尽后，通过原生定向聊天提示受影响玩家；用户可发送专用重试操作到主机，由主机验证当前身份、审批、失败相关性及恢复资格。该操作不开放管理员命令，不引入 LMN，也不把普通聊天文本当机器控制协议。

明确尚未开始交付时，可重新尝试原生基线；可能半包/已 networked 时，不盲目重发清单，提示玩家离开该失败区域的物品加载范围后返回，复用原生队列清理、networked/loaded 撤销及重入基线。离区撤销旧恢复资格，返区按新的当前需求运行，不重抽已完成物资或重启年龄。

当前不新增原地 reset 双端接线。已有原生 clear wire 可以复用，但它本身不会清 isNetworked，且另一个 clear 入口会删除主机权威数据；不能据此声称原生已有安全的原地重同步能力。确切依据见 [Item 局部恢复载体补查](../../.scratch/item-migration-slice/recovery-carrier-facts.md)。

本条细化 ADR0022 的异常操作方式，不改变正常进区自动同步与附近模型呈现，不增完整区域 ACK 或新等待流程。命令文字及数值参数仍属待审阅工程提案；不升级为实施/Runtime验收。
