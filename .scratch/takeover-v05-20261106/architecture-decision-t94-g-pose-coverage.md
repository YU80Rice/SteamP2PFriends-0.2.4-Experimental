## 2. F6最小必测组合：六格，不增加Y偏移

支持域固定为T76当前站姿走/跑，**2类原生stance（STAND、SPRINT）、3个动作/骨骼pose状态（站立idle、站姿walk、sprint）、2个近正交世界朝向**。实际必测表：

| case | 动作/姿态 | 朝向 |
|---|---|---|
| I0 | STAND、静止idle | 预先锁定yaw0，允许±5° |
| I90 | STAND、静止idle | yaw0+90°，允许±5° |
| W0 | STAND、实际行走步态 | yaw0，允许±5° |
| W90 | STAND、实际行走步态 | yaw0+90°，允许±5° |
| S0 | SPRINT、实际奔跑步态 | yaw0，允许±5° |
| S90 | SPRINT、实际奔跑步态 | yaw0+90°，允许±5° |

每格分别做**世界+X 0.10U和世界+Z 0.10U**扰动，各自完整恢复；共6个同帧静态pose事务、12次轴向扰动/恢复。两轴足够检验本水平候选，不要求Y偏移，因为T76写者只改XZ、原生Y/蹲趴偏移不变；跳跃/垂直回归另属M2/M3，不能以本G豁免。

数量依据：一个朝向不能揭穿world/local轴混用；相差约90°是两个不共线基底的最小检查，不把“面向/背向”的共线情况当正交替代。一个静止pose不足以代表蒙皮活动；idle/walk/sprint是已承诺走跑范围内三个具体模式，不能只测idle再宣称跑步可用。不再增加完整动画周期/所有朝向的笛卡尔积；有限六格不是全姿态数学证明，持续插值仍须T76 A/B与安全回归。

每格记录真实stance、测得yaw、动作证据、原生动画/pose时间（能读才填）与骨骼局部pose。**换朝向造成的世界矩阵变化不能冒充换了骨骼姿态**：在相同朝向的I/W/S间，应有非根骨骼的局部TRS差异，并结合真实动作/视频确认状态；采到相同步态交界pose则该格未完成，重新采该格，不以clip名不同替代实际差异。不能为凑姿态由探针改root/yaw、强制Animation.Sample/Animator.Update或改装备。

 crouch/prone/swim不是必加的正样本：T76对它们即时对齐并Suspended，未承诺在这些状态平滑。其负控仍必须证明不据此开启插值、状态切换正确撤偏移；以后扩支持域必须另扩G，不让六格证明外推到蹲趴/游泳。外观、mesh/bones/material/拓扑变化也不由旧六格自动覆盖。

## 3. F7最小口径：比较完整pose，独立hash层不必需

### 3.1 比哪些骨骼、哪些量

原始骨骼集合K取引用身份去重的并集：

- 原Skeleton本身及全部后代Transform（含当前inactive）。
- 每个参与renderer的`bones[]`与`rootBone`实际引用；引用在Skeleton树外也纳入，不只保存BoneCount/路径名称。
- 原玩家Collider所挂Transform及这些引用到原玩家root的父链。沿用已有root/Third保护，重复节点只读一次。

记录每个节点的稳定本次实例身份、父引用/路径、**localPosition/localRotation/localScale的float32位**和**localToWorldMatrix全部16项float32位**；集合/父链不能变化。候选Model叶若本身是K的成员或包含必须保持的骨骼/Collider，不准通过，不能从K删掉它来规避比较。不可读、Unity对象已销毁、空引用不符合资产要求、非有限值、引用集合缺失→`UNKNOWN/POSE_UNAVAILABLE`，不是空表相等PASS。

同一次事务中逐节点逐字段位级相等；可复用已有`BitEqual(float,float)`。**不能用Unity矩阵/向量近似`==`、两位小数、1mm量化、epsilon或bounds相等代替骨骼不变。** 几何残差epsilon只属于表面测量，不是允许挪动原生骨骼的公差。

**不要求另建一层密码学哈希才能判定。** 完整原始数值比较更直接；可对按稳定节点顺序编码的原始位附SHA-256作归档索引，但不能只存GetHashCode/格式化字符串哈希，也不能哈希一棵空树当覆盖证明。导出覆盖节点数/引用及before/after/restore比较结果与首个差异，可按配置保留原始位快照供独立复算。pose指纹与静态profile指纹分开，不能要求idle与sprint的pose哈希相同。

### 3.2 只比较同一动画时刻，不跨帧误红

每格在原生Update/动画求值完成后的同一个主线程相机采样回调内完成，不yield/await、不推进帧、不手动刷新动画或模拟。

1. 必要预热后做**零偏移对照**：读取pose C0、基线烘焙/相关观测、读取C1。C0/C1不一致说明当时pose/异步任务未稳定，格子`UNKNOWN/POSE_UNSTABLE`并停止本次扰动，不归罪于最小方案，也不能签G通过。
2. 每个轴在基线Bake后读P0（也须与零偏移对照相同）→只偏移白名单Model叶→偏移后Bake再读P1→finally恢复自有叶→恢复后Bake再读P2。这样比较点包围实际表面采样，不在Bake之前就宣告pose稳定。要求`P0=P1=P2`逐位、帧/epoch/目标/相机/资产引用一致；烘焙/读取抛错也走恢复并标不可用。下一轴有自己的P0；不拿跨帧动画变化与旧P0比较。
3. 可用性不足/观测期间原生pose自行变化，不能以“动画正常会动”忽略后继续PASS；应记UNKNOWN并重采稳定采样时刻。零偏移对照稳定、扰动过程出现变化时判该事务不满足不变门并停止；不凭这一点独自宣称因果是本探针改骨骼，保留差异作定位。

六格之间骨骼本来可以不同，walk/sprint下一帧自然推进也不应被判失败。不冻结整个游戏/timeScale，不为过G关闭动画/Collider。有限采样不能证明任意外部脚本从未瞬变，因此还须保留T76已审写集仅Model叶、无骨骼setter/无未知gameplay回调的静态边界；不能用“最后还原了”掩盖中途骨骼写入。

### 3.3 为什么现有三种替代物不够

Skeleton根不动，子手指/手臂/衣物骨骼仍可动；sphere旋转或某些对称骨骼变换保持Collider AABB不变；一条受控射线不覆盖全部形状/方向，且无Collider的蒙皮骨骼根本不在bounds集合中。这些变化会把动画自身形变混入`p_after-p_before`，可能伪造随动/撕裂，或让小变化藏在表面epsilon内。F7用来固定这个变量，既服务几何因果也服务原生判定不变，不是可由root/bounds/ray冗余替代的hash装饰。

但F7也**不代替**逐renderer表面max残差与真实画面：骨骼不变而renderer坐标抵消，仍然可能完全不随动；必须如实FAIL，不得用pose相等签几何PASS。

## 4. G结论、实施归属与实际采集

### 4.1 结论粒度

后续轮以新`g_evidence_revision=T94_POSE_GRID-v1`明确区分：单格证据与整profile资格。完整G正结论要求六格各两轴、每个被画renderer均满足T76的`max||(p_after-p_before)-delta||≤epsilon`，恢复门与F7等全部成立。不能用六格均值/P90掩盖任一格/renderer失败，也不能用多个同姿态帧凑六格。epsilon与其来源仍按既有测量契约记录，未指定/来源不成立继续UNKNOWN，不能为适应新姿态自动调大；本票不另造G几何epsilon。

**完整阳性覆盖必需，反例可以短路。** 一格pose稳定/观测有效而实际表面不随动或撕裂，已足以否定该profile最小路线，立刻按T76停止，无需再扰动余下格子求PASS；任何已证物理/权威门被破坏也立即停止。缺骨骼稳定证据时，几何不符只是未隔离混淆的观测，不能据此独断所有姿态原理不可能；但绝不能授G准入。

旧单格JSON即使字段为`PASS`，只按当时已测范围保留，**不升级为T76完整G资格**；附本裁决说明，不能改历史原始结果。新汇总缺revision/任一case/pose比较不可用→完整G为UNKNOWN。已证几何或安全反例→FAIL。没有任何这样的证据授予Bug1修复PASS。

## 5. 最小离线守卫、变异与发布边界

后续用真实生产比较/导出入口验证，不另写假的G判定器：

1. 骨骼集合覆盖：Skeleton根不变而一个后代旋转/scale变、外部绑定骨骼变、被Collider引用的变换变→拒；缺一个必需节点/不可读→UNKNOWN。相同pose逐位通过；正常下一格不同pose不被跨格误拒。
2. 一个轴扰动后改变再恢复到同一最终pose，P1阶段必须拒；仅检查P2或Skeleton根的变异须红。去掉实际采集/比较的生产调用也须由接线守卫红，不是只测helper。
3. 六格缺任一/同heading重复/把X与Z记成两pose/动作名变但实际局部pose相同，不能汇总PASS。六格全合格→允许资格；其中一renderer残差超epsilon→FAIL，不被其它点/格均值遮住。
4. 同步控制表面与骨骼证据：骨骼稳但表面不动→FAIL；表面看似随动但骨骼未知/在变→不得PASS；回滚失败或已证物理门变化→停止，不能继续下一格。

这些是未来可红测试要求，本票未执行用例。生产字节、证据schema和G准入语义都会变化，必须重新绑定最终source/test/DLL身份，工程+规格双轴；**不符合T57 TEST_STRENGTHEN_ONLY**。t92若只作为局部采样诊断交付，仍须其适用审查CLEAN并在说明中保留F6/F7边界；本裁决不豁免其它未关闭阻断项。G资格未齐继续阻塞插值启用/可行性宣称，不因诊断默认OFF就宣称G完成；不额外阻塞完全独立且已过其它门禁的Bug3保护功能。
