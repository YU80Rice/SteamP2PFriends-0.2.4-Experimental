## §2 R30-01：seam 改为「替换动作」

生产 `Core/Registration/SteamP2PFriendsPlugin.PatchRegistrationDiagnosticsModules.cs`：

```csharp
// R30-01 测试缝：把「某段的执行动作」替换成包装动作（section, real）→ wrapper。
// RunDiagnosticSectionForTest 仍以唯一调用点 `a()` 执行，注入只能包装、不能跳过；
// 生产无任何代码路径写入该字段（Reset 清零），故生产恒走真实 action。
internal static Func<string, Action, Action> DiagnosticStageActionForTest;

// R30-01：唯一的动作执行点。seam 只能替换/包装动作，不能跳过调用；
// 生产（seam == null）直接执行真实 action，零行为变化。
private static void RunDiagnosticSectionForTest(string section, Action action)
{
    Func<string, Action, Action> seam = DiagnosticStageActionForTest;
    Action a = seam != null ? seam(section, action) : action;
    if (a == null)
        throw new InvalidOperationException("diagnostic stage action is null for section: " + section);
    a();
}
```

## §3 R30-02：`Bug1ProbePatch.RegisterManual` 返回值语义

依据 `Platform/Diagnostics/Patches/Bug1ProbePatch.cs`：

| 位置 | 代码 | 语义 |
|---|---|---|
| :30 | `public static bool RegisterManual(Harmony harmony)` | — |
| :32 | `if (harmony == null) return false;` | 配置缺失 → 失败 |
| :33 | `if (Attempted && _harmonyId == harmony.Id) return true;` | 幂等重入 → 成功 |
| :38 | `if (!Bug1ProbeRuntime.Enabled) return true;` | **未启用 → 成功（不安装，不是失败）** |
| :39 | `return Install();` | target 解析/Verify/异常 → false（安装失败） |

结论：`false` ⇔ 安装失败或 harmony 缺失；「未启用」恒返回 `true`。因此 lambda 内把 `false` 转成 `InvalidOperationException`，由既有 `catch` 折进 `ok=false` 并输出 `Bug1ProbePatch.RegisterManual 失败` 日志；不再丢弃。生产 `_harmony` 非空，故不会把「未启用」误判为失败。
