# C-P2-Item-01 实施规格

## Problem / Solution

客机首次到访不应遇到半准备世界或已在无人阶段过期的自然物资。输入可用后做一次全图数据准备，再由首次有效需求启动区域自然计时和原生交付。

## Fixed inputs

用户2026-10-08批准本票；研究插件起点 `57e3c4e4411b4f8831f0bf6d489b9fea9922c47c`，SDK `ea7b4973af5ba10f62baad2bfde36ab2e5b060eb`。读 [共同输入](../item-migration-slice/execution-inputs.md)、[主规格](../item-migration-slice/spec.md) 的准备/来源/计时政策及ADR0019、0021、0023、0025。

## Implementation decisions

- 输入包含原生区域数组、物资点和资产；Host活动/房间发布/网络建立不等于Item就绪。合法空区也完成准备；原生模式例外保留。
- Item注册真实共享Demand Policy/Execution Port，消费Core观察者及身份，覆盖Host和既有World Presence Observer；不建立私有扫描/第二仓库。
- 准备结果绑定实际地图和当前会话；Core绑定不清空同轮已准备数据，迟到回调不进入下一会话。准备失败不能标记成功。
- 来源按自然创建/实际掉落路径识别，不仅看isDropped或单一生成标志；回调嵌套掉落不能因原生首次列表替换丢失。已核实实际掉落期限按U3DS分类，未知来源不授予自然休眠资格。
- 首次有效需求仅为预生成自然物品建立自然寿命及刷新起点；实际掉落年龄保持。读取原生单调时间/配置，不混入现实日期。
- 自然数据准备、首次启计、观察者交付分别提交；原生bool不等于动作完成。第二观察者获得独立基线但不重复准备或启计。
- 通过真实候选入口衔接Host本地和Guest原生基线，不要求全区模型/ACK；候选与旧Writer同一会话只选一条生产路径。

## Testing decisions

- 用户批准的高层入口使用真实共享投影/编排及Item政策，仅替代时钟、Unity/原生动作、网络薄边界；沿用Resource生产接缝及共享引擎fixture先例。
- Red覆盖提前请求、空区、重复加载/Core绑定、两个观察者首次需求、旧回调及嵌套实际掉落；Green观察实际数据、计时、交付次数/顺序。
- 核对原生准备/生成及区域清单真实注册和调用链；不以孤立账本或空端口证明迁移。必要来源/计时/动作结果缺口必须在本票解决。
- 记录本票结果与未完成Runtime项；多人实际首访/Host本地效果最终由06采证，本票不伪报Runtime PASS。

## Out of scope / Deliverable

不做返区结算、持续自然周期/独立到期调度、失败重试、旧Writer正式退役、20米校验或其他域迁移。交付本票可独立验证的候选生产路径、Red/Green/回归及原生绑定记录；不将未完整候选当正式体验部署。
