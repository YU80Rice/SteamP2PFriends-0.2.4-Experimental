# C-P2-Item-02 实施规格

## Problem / Solution

原有全图周期会提前消耗未访问自然物资并持续处理无人区。基于共享有效需求运行自然周期，实际掉落使用独立有界到期处理。

## Fixed inputs

用户2026-10-08批准；依赖01实现/验证记录。研究插件 `57e3c4e4411b4f8831f0bf6d489b9fea9922c47c`，SDK `ea7b4973af5ba10f62baad2bfde36ab2e5b060eb`；执行起点包含01实际产物。读 [共同输入](../item-migration-slice/execution-inputs.md)、[主规格](../item-migration-slice/spec.md) 有需求/休眠政策及ADR0019、0025。

## Implementation decisions

- 只消费共享投影的当前Item有效需求；零需求立即停止实时自然周期，不能只看Acquire/Release或滞回租约是否存在。
- Item释放滞回固定2秒，业务时钟持续推进；Release不删除权威ItemData或首次启计记录，短暂重入不重新启计。
- 有需求时保留原生配置、阈值、数量、抽表、点位、安全区及扩展规则；真实删除/创建/计时结果以动作效果为准，不以bool猜完成。
- 延续01来源元数据，跟踪后续自然创建、玩家及已核实僵尸/动物/资源掉落；自然用Despawn_Natural_Time，实际掉落用Despawn_Dropped_Time。
- 实际掉落计龄从实际创建开始；到期与自然启计/租约/观察者无关，包含未访问区域。有界推进并保留原生模式例外，不承诺阈值瞬间清除。
- 原生回调嵌套实际掉落不能误分自然或被替换丢失；未知来源不能自动作为可休眠自然项。
- 不新建全图每帧模拟/第二物品仓库；候选与旧全图周期Writer不能同时写同一会话。

## Testing decisions

- 使用01高层生产入口及可控时钟；观察自然动作、实际掉落删除和共享需求变化，不只测租约账本。
- Red覆盖两人聚合/依次离开、零需求/滞回期间停自然周期、未访问掉落到期、不同自然/掉落期限及嵌套来源。
- 验证首次启计不回归，存活旧物计时不归零；Resource/Collision既有投影、Release及模式路径无回归。
- 记录调度入口与真实原生绑定，最终实际计时/远端效果交由06；本票没有完整返区行为，不把它宣称为完成Item迁移。

## Out of scope / Deliverable

不做返区补算、结算等待/完成门、异常恢复、正式Writer切换或20米校验。交付可独立演示的需求驱动自然周期和独立掉落到期路径，以及本票测试/证据记录。
