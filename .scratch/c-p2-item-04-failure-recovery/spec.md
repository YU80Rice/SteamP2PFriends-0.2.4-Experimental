# C-P2-Item-04 实施规格

## Problem / Solution

现有基线拒绝可留下永久缺物状态，无限重试又会消耗房主资源。仅对实际异常有限恢复，耗尽后提供局部提示和用户恢复入口。

## Fixed inputs

用户2026-10-08批准；依赖03的结算幂等性和完成门。研究插件 `57e3c4e4411b4f8831f0bf6d489b9fea9922c47c`，SDK `ea7b4973af5ba10f62baad2bfde36ab2e5b060eb`。读 [共同输入](../item-migration-slice/execution-inputs.md)、[主规格](../item-migration-slice/spec.md)、[恢复载体事实](../item-migration-slice/recovery-carrier-facts.md) 及ADR0022、0024。

## Implementation decisions

- 正常准备、共享分帧结算、等待同次结果、无故障证据的网络/模型等待与真实失败分开；正常待完成不能转成失败并消耗预算。
- 真实异常恢复链首次尝试加最多3次自动重试，间隔0.5/1/2秒，整链最多10秒（先到者）；从首次检测的实际异常起算，重复回调不能重置链。
- 通用编排政策在共享层有界扩展，向后兼容Resource/Collision；quietAttempts仅静默日志，不是次数上限，不复制Item私有通用重试机。
- 每次恢复先核对原生已执行结果，只推进确认未完成步骤；不能重新抽货或回滚已经成功删除/补货，结果无法确认则维持不可用并报异常。
- 明确尚未开始交付的失败可当前区域重试；可能半包/已networked不得盲目重发packet0、askClear或新增原地reset协议。
- 耗尽后使用原生定向聊天提示，命令 `/spfitemretry` 到达主机；检查审批、会话/连接身份、当前需求、失败区域及预算，同观察者/同区域至少间隔10秒。
- 可能半包指导离开该区域完整ITEM_REGIONS加载范围再回来，复用原生清loaded/networked与取消队列；返回是新需求正常尝试，不继承旧恢复资格或重复结算。
- 离区/断线/身份失效撤销旧观察者恢复资格；有效区域已启动作业仍按03收尾。区域权威失败影响数据依赖者，单观察者发送失败不拖累其他观察者/域/区域。
- 发送调用返回/可靠标志不证明未发或送达；保留原生RPC，不新增隐藏聊天控制协议、管理员权限、LMN或全区ACK门。

## Testing decisions

- 高层入口注入确定失败，Red覆盖次数/期限先到、重复回调、手动频控/身份校验、故障隔离、正常长结算不失败。
- 覆盖未发送前安全重试、可能半包不盲重发、离区清理/返区资格、旧连接/会话拒绝及恢复不重复写仓库。
- 原生聊天到主机控制入口与可靠发送证据分别检查；fake只替代外部动作，不代替恢复政策。共享引擎及Resource/Collision恢复/Release回归通过。

## Out of scope / Deliverable

不重写03结算、不退役旧Writer、不新增原地双端reset、全房间停机或新交互机制。交付候选路径局部失败闭环、固定预算与本票测试/绑定记录；正式会话切换留05。
