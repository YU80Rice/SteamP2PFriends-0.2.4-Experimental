事实补查由新的 research turn 只读核对 SDK：周期刷新先抽一个 spawn，检查同区全部现存 ItemData（含实际掉落和本轮新加入记录）的距离平方 <4，再抽出一个物品 ID；同一点成功后会占位，不会因为品类多就同次各刷一件。原生失败尝试会消耗本轮缺量预算，不保证补满。首次 generate 的 valid 列表去重与周期距离检查不同；第三方回调改点、跨区与物理移动不受上述检查的普遍保证。
