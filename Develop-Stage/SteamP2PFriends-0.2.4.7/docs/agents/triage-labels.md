# Triage Label Vocabulary

This repository uses the 5 canonical triage labels:

| Label | Role | Description |
|---|---|---|
| `needs-triage` | Initial state | New issue needing assessment and triage |
| `needs-info` | Blocked on info | Waiting for clarifications or evidence from human |
| `ready-for-agent` | Agent actionable | Clear specification ready for automated implementation |
| `ready-for-human` | Human actionable | Requires physical testing, human verification, or decisions |
| `wontfix` | Discarded | Not planned or out of scope |
