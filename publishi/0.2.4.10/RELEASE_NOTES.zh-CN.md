# SteamP2PFriends 0.2.4.10 实验预发布

本版更新物品生命周期与多人同步，重点修复房主／客机物资不刷新、幽灵物品、入服半包提示，以及再开世界后的物资准备问题。

## 更新内容

- 修复房主刷新物品时可能出现不可拾取的幽灵副本，统一共享呈现与原生队列的交接。
- 修复原生玩家身份对象的重载判空异常，避免客机加入后的绑定／补偿解绑失败将物资链升级为持续停写。
- 修复合法客机首次进入时读取身份的时点错误，避免发送前拒绝被误报为“可能半包”，减少入服区域提示刷屏。
- 区分合法空物资区与尚未就绪的输入；确认未发送的清单使用有界续送，未知发送结果仍保留隔离保护。
- 客机退出、重连时按实际连接身份精确清理，避免迟到的旧回调影响新连接或其他玩家。
- 每次新开世界重新准备当前世界的物资与准入状态，不沿用上一世界的就绪标记。
- 将返区物资结算从一秒调度门中拆出，按原预算逐帧推进，改善需要等待或离开再进入才出现物资的问题。

## 验证情况

- 当前完整自动化验证：635/635通过，源码与发布材料完成独立双轴审查。
- 2026-10-29完成1名房主＋2名客机实机测试；维护者确认物品刷新、僵尸AI和掉落正常，无幽灵物品或不刷新问题。日志支持双客机在线、退出重连及同进程再开世界。

## 下载与安装

下载附件 **`SteamP2PFriends-0.2.4.10.zip`**，压缩包结构：

```text
BepInEx/
└── plugins/
    └── SteamP2PFriends.dll
```

1. 房主和所有客机退出游戏，分别备份现有的`BepInEx/plugins/SteamP2PFriends.dll`。
2. 确认已安装适用的BepInEx；本包只包含插件，不附带BepInEx或游戏程序集。
3. 将压缩包解压到Unturned游戏根目录，合并`BepInEx`目录并替换同名插件。不要保留多个版本的插件DLL同时加载。
4. 房主和所有客机使用同一份DLL，再通过原有启动方式或UMM进入游戏。
5. 如需回滚，所有端退出游戏后恢复各自备份的DLL。

本版沿用 **Experimental** 通道，不覆盖0.2.3旧实现仓库。插件目标为`.NET Framework 4.7.2 / AnyCPU`，运行依赖由现有游戏与BepInEx环境提供。
